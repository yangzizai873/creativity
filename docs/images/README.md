# 截图

市场收录要求 1–5 张真实产品截图，第一张为封面，建议 16:9、宽度至少 1280px、单张不超过 2 MiB。

需要在**最终可安装版本**上、在 DSH Desktop 里实际打开后截取，建议包含：

1. 首屏 / 创意清单
2. 创意详情（含「这件事需要什么」联想）
3. AI 打样初稿
4. 查新与商用评估
5. 网络灵感

文件名：`overview.png`、`associate.png`、`draft.png`、`research.png`、`web-inspiration.png`。

放入本目录后，收录 YAML 的 `screenshots` 填：

```
https://raw.githubusercontent.com/yangzizai873/creativity/main/docs/images/overview.png
```

其余同理替换文件名。截图里不要包含个人信息、密钥或客户数据。
