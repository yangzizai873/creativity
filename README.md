# 创意堂

个人创意工作台：把闪过的想法记在一处，整理、筛选，再把选中的想法变成下一步行动。需要 AI 一起想的时候，再打开对话。

## 能做什么

- **一句话记录**：输入标题回车即存，不用先建会话或选文件夹。
- **主动录入**：右上角「新建创意」可一次填好标题、描述、标签、状态和下一步；首次使用页也提供「填写完整信息再保存」。Ctrl + Enter 保存，Esc 取消。
- **整理创意**：描述、标签、四档状态（火花 / 推进中 / 已落地 / 搁置），以及「下一步」。
- **查找**：按标题、描述、标签、下一步搜索，按状态筛选。
- **查新与商用评估**：单条创意内点「开始评估」，工作台会用关键词联网检索，再由当前默认模型给出三件事——有没有人提出过（附可点开的来源）、商用价值（0-100 分与理由）、可以用在哪些方面（2-5 个方向）。结果保存在这条创意里，可随时重新评估。
- **AI 联想与打样**：记录创意后自动联想「要做成它需要什么」——按重要性列出 4-6 个具体领域（如 PCB 绘制、嵌入式程序、机械结构、物料），每个领域带第一步和 AI 可产出的东西；点「让 AI 打个样」会直接生成一份初稿（清单、示例代码、模板），保存在这条创意里。
- **网络灵感**：右上角「网络灵感」进入独立页面，从公开网络找「有人提出、但还没看到成熟实现」的创意线索；可按主题搜索、「换一批」，一键收进创意堂（自动打上「网络灵感」标签，来源链接写进描述）。
- **按需 AI 协助**：右侧抽屉打开后才创建或恢复工作台会话；对话与创意堂关联，关闭后回到业务页面。

数据保存在本机 DSH 数据目录的 `creativity-hall/ideas.json`（由 `cordis.patch.yml` 的 `root` 决定）。卸载插件不会删除该目录。

### 评估说明与边界

- 评估会使用 DSH 的联网检索能力和当前默认模型，每次点击会消耗少量模型额度，通常十几秒完成。
- 会把这条创意的标题、描述和标签发送给模型，并用标题与标签作为公开网络检索的关键词；不会上传整个创意库。
- 结论是辅助判断，不构成市场调研或投资建议；来源列表只包含检索返回的链接，模型引用编号见摘要。
- 联网检索失败时仍会给出基于创意本身的判断，并标注「本次未联网」；模型不可用时按钮会提示原因，可稍后重试。

### 网络灵感说明

- 默认轮流使用几组公开线索关键词（如 SomebodyMakeThis、halfbakery、未实现发明），也可以输入自己的主题。
- 先联网检索，再让模型提炼成具体创意卡片；模型不可用时直接展示检索结果，不做提炼。
- 结果来自公开网页，未逐条核实「是否真的没人实现」，卡片上保留来源链接供自行判断；「收进创意堂」只创建一条本地创意，不会替你去实现或联系来源。

### AI 联想说明

- 新建创意后会自动联想一次；也可以在详情里点「重新联想」。每次会消耗少量模型额度。
- 打样按单个领域生成，内容是可直接使用的初稿，不是成品：代码需要自己跑通，硬件清单需要按实际型号核对。
- 联想结果和初稿都保存在这条创意里，随创意一起备份，不会因为换会话丢失。
- 模型偶尔不按 JSON 格式输出（加解释、包代码块、被截断）：工作台会先尽量解析，失败后自动让模型「改写成 JSON」重试一次；仍失败会提示重试，并把原始输出写进 Harness 日志方便排查。

## 安装

工作台是 DSH 插件包，仓库地址：<https://github.com/yangzizai873/creativity>。

从 GitHub 源码安装（无需构建，客户端入口已在 `lib/client.js`）：

```powershell
dsh plugin --profile web add github:yangzizai873/creativity
```

从本机打包安装：

```powershell
pnpm pack
dsh plugin --profile web add .\dsh-creativity-hall-0.6.0.tgz
```

也可以把本目录作为本地目录安装（开发时更新更快）。安装完成后需要完整退出并重新打开 DSH Desktop 才会加载。

打开方式：展开左侧栏，点击左上角「工作台」右侧的当前工作台名称／切换区域，选择「创意堂」。未显示时，进入「工作台管理 → 已安装」查看条目与运行状态。

## 布局

业务整页优先（`customFrame`）：首次进入直接是创意清单或「先记下第一个想法」的入口，不占用常驻会话区。AI 对话只在用户点击「AI 协助」后出现，使用宿主提供的 `conversation` 节点。

## 包结构

```
package.json           # npm 与 DSH 插件声明
cordis.patch.yml       # 把服务端入口插入插件树
dsh/index.js           # 服务端：/api/creativity-hall/* 读写 ideas.json
lib/client.js          # 客户端：注册并渲染业务面板（单文件模块）
scripts/check-workbench-package.mjs  # 包自检
```

## 自检

```powershell
node scripts/check-workbench-package.mjs
node scripts/check-workbench-package.mjs --tarball .\dsh-creativity-hall-0.6.0.tgz
pnpm test    # 服务端接口 + 客户端注册接线
```

`test/visual/harness.html` 用宿主同版本 React 18.3.1 在浏览器里渲染真实业务面板，可调 `?w=420` 等参数检查不同容器宽度；`test/visual/*.png` 是自检截图。
